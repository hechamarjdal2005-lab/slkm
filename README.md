# SLKM Transport

Installation de la base Supabase : suivre uniquement [supabase/FINAL_DATABASE/README.md](supabase/FINAL_DATABASE/README.md), puis exécuter `01.sql` à `09.sql` dans cet ordre.

Les anciens SQL sont sauvegardés hors de la structure active, avec vérification SHA-256 : [manifeste de sauvegarde](docs/FINAL_DATABASE_BACKUP.json).

Validation locale : `npm run test:sql`, `npm run typecheck`, `npm run lint`, `npm run build`. Voir le [rapport de vérification](docs/FINAL_DATABASE_VERIFICATION.md).
